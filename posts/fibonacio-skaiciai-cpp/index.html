Fibonačio skaičių skaičiavimas su C++

Paprastas Fibonačio sekos skaičiavimo pavyzdys C++ kalba.
September 12, 2026

Fibonačio sekoje kiekvienas skaičius gaunamas sudėjus du prieš jį esančius skaičius. Seka prasideda taip: 0, 1, 1, 2, 3, 5, 8, 13...

Žemiau pateikta C++ programa paprašo įvesti norimą sekos narių skaičių ir juos apskaičiuoja iteraciniu būdu:

#include <iostream>

int main() {
    int n;
    std::cout << "Kiek sekos nariu apskaiciuoti? ";
    std::cin >> n;

    if (n < 1 || n > 93) {
        std::cout << "Iveskite skaiciu nuo 1 iki 93.\n";
        return 1;
    }

    long long pirmas = 0;
    long long antras = 1;

    for (int i = 0; i < n; ++i) {
        std::cout << pirmas << " ";
        if (i < n - 1) {
            long long kitas = pirmas + antras;
            pirmas = antras;
            antras = kitas;
        }
    }

    std::cout << '\n';
    return 0;
}

Šio algoritmo laiko sudėtingumas yra O(n), o papildomos atminties sąnaudos – O(1), nes saugomos tik dvi paskutinės sekos reikšmės. Naudojant long long galima tiksliai atvaizduoti pirmąsias 93 reikšmes – nuo F(0) iki F(92).
